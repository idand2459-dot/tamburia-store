# ארכיון — אב-הטיפוס הראשון

הקבצים כאן הם הגרסה הראשונה של הפרויקט, מלפני מעבר ל-React:
אתר סטטי בשלושה קבצים (`index.html`, `script.js`, `style.css`).

**הם אינם מוגשים ואינם בשימוש.** הם נשמרים כאן לצורך התייחסות בלבד.

כמה דברים ששווה לדעת לפני שמסתמכים עליהם:

- התוכן שייך לגרסה מוקדמת של הרעיון ("טמבוריה סטור", חנות כלי הקשה)
  ואינו מתאר את החנות בפועל.
- `script.js` בונה כרטיסי מוצר עם `innerHTML` בלי בריחת תווים — שם מוצר
  שמכיל HTML היה מורץ בדפדפן. זו אחת הסיבות שהם אינם מוגשים.
- עד ה-refactor הם הוגשו דרך `express.static('.')` משורש הפרויקט,
  מה שחשף גם את `server.js` ואת `package-lock.json` לכל דורש.

החזית בפועל היא אפליקציית ה-React שב-`client/`, ומוגשת מ-`client/build`.
